# Prompt Engineering – Python Practice

Practice assignments completed while learning prompt engineering with Python.

## How to install libraries
1. Install the libraries: `python -m pip install textblob nltk`
2. Go to the assignment folder: `cd 927.4.1_Sentiment-analysis`
3. Run a task: `python task1.py`

## Contents
- **927.4.1_Sentiment-analysis**: sentiment analysis with TextBlob (Tasks 1–3). Course lesson: [Sentiment Analysis and Semantic Understanding](https://perscholas.instructure.com/courses/3601/pages/lesson-927-dot-4-sentiment-analysis-and-semantic-understanding)
- **NLTK_Lab**: NLTK labs on NER, stemming, lemmatization, and POS tagging

## NLTK Lab
- Techniques used: tokenization, stemming, and lemmatization
- How to apply Named Entity Recognition (NER) and Part-of-Speech (POS) tagging in Natural Language Processing (NLP)
